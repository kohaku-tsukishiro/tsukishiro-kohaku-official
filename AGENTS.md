# Moonlight White Tiger Project

See CLAUDE.md for the repository guide (structure, dev commands, brand rules).

## Development

Site development happens in `website/`:

```
cd website
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Brand rules

- Follow `docs/brand-guideline.md` and `docs/design-system.md`.
- Shared Design System: `website/public/brand/brand.css` (tokens + .mwt-* / .hud-* components).
- Futuristic, premium, clean. No flashy neon, no cheap animations.
